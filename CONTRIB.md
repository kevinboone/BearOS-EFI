This program contains elements that are partially or fully derived from the 
following works.

The compact implementation of the print() function is from "nanoprintf",
by Charles Nicholson, released into the public domain.
https://github.com/charlesnicholson/nanoprintf

Some of the date conversion code was derived from Michael G Schwern' y2038 project,
copyright (c)2007-2010, released under the MIT licence.
https://github.com/evalEmpire/y2038/

The FAT filesystem handler is provided by "ChaN", under licence terms that
I believe are compatible with the GPL. See 
https://elm-chan.org/fsw/ff/doc/appnote.html#license for more information.

Some of the ACPI management code is derived from Abz_Shutdown, by 
Abdallah Terro .
https://github.com/aterro/Abz_Shutdown
