# Contents of the BearOS/EFI archive

## Persistent files and directories 

`config.mak` -- general configuration settings for the build; not much here at present.

`CONTRIB.md` -- contributors and open-source licence information

`docs/` -- documentation

`lib/` -- BearOS standard C library

`libbearos/` -- BearOS application support library. This contains utility
functions that many BearOS programs will need, such as support for
variable-length strings, linked lists, Unicode conversion, etc.

`rootfs` -- Directories and files that will comprise the root directory on the
final installation. This directory gets merged into the directory `files`,
along with the compiled utility programs, during the build. There should be no
compiled code in `rootfs`.

`programs/` -- all the utility programs: `cp`, `rm`, etc.

`start/` -- the application start-up code. The compiled `start.o` will be linked
with the compiled application. 


## Files and directories generated during the build process

`bearos.iso` -- bootable DVD or USB flash image

`dummy/` -- the root directory for the bootable image. Normally it contains
only `bearos.img`, but other files could be added later.

`files` -- the full root directory, generated by merging `rootfs/` with the
compiled utilities and kernel.

`img` -- contains `bearos.img`, which is the floppy disk image containing the
kernel and core utilities, which will be incorporated into the El-Torito DVD
image. The image in `img/` gets transferred to `dummy/`, which forms the
root of the DVD filesystem.

`kernel/bearos` -- The Linux test version of the BearOS kernel. Use in
conjunction with `linuxdisk.img`.

`XXX/build/` -- most of the source directories get a `build/` directory during
compilation, which will contain the compiled output. Of particular importance
is `kernel/build/bearos.efi`, which is the EFI program that comprises the
kernel itself.
